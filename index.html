Overview

SekoTalk-H3 follows changing motion prompts while generating continuous audio and video, preserving character and scene through reusable context.

Technical details

01

Training

Causal SFT
MiniMax-H3 is adapted to chunk-wise audio-video generation with ground-truth clean history and a chunk-wise flow-matching objective.
Four-step distillation
Self-Gradient-Forcing distillation reduces inference to four denoising steps per chunk, preserving the causal architecture and prompt design.
02

Prompt control

Global & motion prompts
A persistent global prompt anchors identity and scene. Independently encoded motion prompts govern each segment and switch at chunk boundaries.
Prompt-agnostic history
Both passes read retained clean media history. Denoising also attends to the active motion prompt; clean commit excludes it and writes reusable media KV.

Designed for Continuity

Key Features

Fine-grained motion control in one audio-video framework.

01 / EFFICIENT GENERATION

Four steps. Every chunk.

Self-Gradient-Forcing distillation generates each audio-video chunk in four denoising steps while reusing the accumulated causal history.

02 / FLEXIBLE CONDITIONING

Three modes. One framework.
Reference Image → Video and Audio
Reference image → video + audio
Reference Image and Audio → Video
Target audio → video; VAE-reconstructed audio
Reference Image and Reference Audio → Video and Audio
Reference audio → target video + audio

All three modes use a reference image.

03 / LONG-FORM GENERATION

A consistent world. Evolving behavior.

A persistent global prompt anchors the subject, appearance, and scene. Segment-level motion prompts change local behavior without redefining that world.
